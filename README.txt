LUCIANA PORTFOLIO — HTML + CSS

Open index.html in Visual Studio Code and choose “Open with Live Server”.

To customize:
1. Replace the SVG sample covers in assets/ with your real project images. If you use JPG or PNG, update each img src in index.html and in the corresponding projects/*.html file.
2. Add your own images, descriptions and links to the three project pages, or copy a card and a project page to add more projects.
3. In index.html, replace YOUR_EMAIL@example.com and YOUR_LINKEDIN_URL. The sample email and LinkedIn link are not your real contact information.
4. Google Fonts are loaded online; the page works offline with its fallback fonts.

The sample SVG images are illustrative covers, not your actual project artwork.
